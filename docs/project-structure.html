Vòng Đời Hoạt Động Của Hệ Thống SMASH-VN

Mô tả các bước hệ thống xử lý khi chạy file SmashVnApplication.java, từ cấu hình môi trường đến phục vụ request HTTP.

1. Khởi chạy JVM & Nạp Biến Môi Trường (.env)

Khi chạy câu lệnh khởi động ứng dụng Spring Boot, lớp DotenvEnvironmentPostProcessor sẽ tự động được gọi đầu tiên (nhờ cơ chế SPI Spring Factories). Lớp này thực hiện đọc tệp cấu hình cục bộ .env, kiểm tra sự tồn tại của các key như DB_URL, API key và đẩy động các biến này vào Spring Environment Context để dùng chung trong file application.properties.

java -jar target/smashvn-shop-0.0.1.jar --spring.profiles.active=prod

2. Quét Annotations & Khởi tạo Spring Bean

Hàm main() trong SmashVnApplication.java chạy, kích hoạt annotation @SpringBootApplication. Spring Container tiến hành quét toàn bộ package com.smashvn.shop.* để khởi tạo và lưu trữ các lớp cấu hình, các RestController, các Service, và Repository thành các Singleton Beans trong ApplicationContext.

@SpringBootApplication
public class SmashVnApplication {
    public static void main(String[] args) {
        SpringApplication.run(SmashVnApplication.class, args);
    }
}

3. Đồng Bộ Hóa CSDL & Migration Tự Động

Ứng dụng kết nối tới MySQL/PostgreSQL thông qua cấu hình Spring Datasource. Công cụ Flyway Migration tự động quét thư mục db/migration/ để thực thi các file SQL nâng cấp phiên bản CSDL (V1.1 -> V1.18). Đồng thời, PlaintextPasswordMigrator kiểm tra nếu có tài khoản nào cũ trong bảng tai_khoan chưa băm mật khẩu thì tự động mã hóa BCrypt một lần. Lớp EmployeeMigrationRunner thực thi để migrate dữ liệu nhân viên sang định dạng chuẩn.

Flyway PlaintextPasswordMigrator.java EmployeeMigrationRunner.java

4. Thiết Lập Bộ Lọc Bảo Mật & Routing Pipeline

Lớp SecurityConfig.java khởi tạo Filter Chain của Spring Security. Thiết lập các filter bảo vệ như CSRF Protection, CorsFilter, và đăng ký các filter tùy biến như UploadSecurityFilter. Tiếp theo, WebMvcConfig đăng ký AdminInterceptor vào danh sách Interceptors để chặn đường dẫn /admin/** và liên kết thư mục vật lý uploads/ để hiển thị ảnh.

SecurityConfig.java WebMvcConfig.java AdminInterceptor.java UploadSecurityFilter.java

5. Nhận Request HTTP & Phục Vụ Người Dùng

Khi Tomcat Server sẵn sàng trên cổng 8080, mọi request HTTP từ trình duyệt gửi tới sẽ đi qua các Security Filter -> Interceptors -> DispatcherServlet tìm đúng Controller tương ứng để gọi Service -> Repository -> Database để trả về view Thymeleaf hoặc dữ liệu JSON.

[Tomcat Started on Port 8080] System is ready to handle traffic.
