1. Đổi / Trả Hàng & Hoàn Tiền 100% HOÀN TẤT XUẤT SẮC Video bằng chứng MP4/MOV, nút Duyệt / Từ chối, modal upload chứng từ ảnh bắt buộc. Không còn tồn đọng tiếng Anh.

6. Bảo Mật, Lỗi Mạng & Exception 90% HOÀN TẤT CẦN TINH CHỈNH Template lỗi 404, 500 được thiết kế đẹp mắt và thân thiện. Cấu hình Custom AccessDeniedHandler (403) và AuthenticationFailureHandler.

// CODE HIỆN TẠI (app.js): .catch(function(error) { if (typeof Swal !== 'undefined') { Swal.fire({ icon: 'error', title: 'Thanh toán thất bại', text: error.message }); } else { alert(error.message); } });
// ĐỀ XUẤT KHẮC PHỤC CHUẨN TIẾNG VIỆT: .catch(function(error) { var userMsg = 'Không thể kết nối đến máy chủ. VAL-09 Bắt ngoại lệ vượt quá giới hạn dung lượng upload Multipart (50MB Video / 5MB Ảnh)
CRITICAL GlobalExceptionHandler.java: L85

Nguyên nhân: Khách upload video bằng chứng đổi/trả lớn hơn 50MB bị Tomcat chặn và hiển thị trang lỗi 500 tiếng Anh.

// HIỆN TẠI: Chưa bắt MaxUploadSizeExceededException // Server trả về: org.springframework.web.multipart.MaxUploadSizeExceededException: Maximum upload size exceeded
// ĐỀ XUẤT KHẮC PHỤC CHUẨN TIẾNG VIỆT: @ExceptionHandler(MaxUploadSizeExceededException.class) public String handleMaxSizeException(MaxUploadSizeExceededException exc, RedirectAttributes redirectAttributes, HttpServletRequest request) { redirectAttributes.addFlashAttribute("errorMsg", "Dung lượng tệp tải lên vượt quá giới hạn (Tối đa 50MB cho video và 5MB cho hình ảnh)!"); String referer = request.getHeader("Referer"); return "redirect:" + (referer != null ? referer : "/"); }
